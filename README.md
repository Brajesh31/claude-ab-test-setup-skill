# AB Test Setup Skill

A Claude skill for planning, designing, and implementing A/B tests and experiments.

## Repository contents

- `SKILL.md`: original instructions for experiment planning, test design, and implementation.

## Usage

Install this skill in the skills directory used by your Claude-compatible environment. Keep `SKILL.md` at the skill root.

Use it when planning split tests, evaluating variants, defining hypotheses, or setting up experiments.
